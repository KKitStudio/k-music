## 三、本次修复的真实缺陷
1. **旧库 schema 迁移**：测试/旧库若残留 legacy `playlists(kind NOT NULL, ...)`，`CREATE TABLE IF NOT EXISTS` 不会重建 → `init_schema` 检测 `pragma_table_info` 中 `kind` 列，存在则 DROP `playlists`/`playlist_items` 重建。
