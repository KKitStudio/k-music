## 歌词功能（任务 #55/#61）

- 新增 `app/core/src/lyrics.rs`：来源优先级 = 同名 `.lrc`（sidecar）→ 音频内嵌（embedded）。
  - `find_sidecar()`：精确 `<stem>.lrc` + 目录内大小写不敏感扫描。
  - `decode_bytes()`：UTF-8 BOM / UTF-16 BOM / UTF-8 / GB18030（新增依赖 `encoding_rs 0.8.44`，feature `["std","alloc"]`）。
  - `extract_embedded()`：ID3v2 `USLT`（**自研解析**：synchsafe 尺寸、扩展头、反同步、逐帧扫描、内容描述符分隔、编码字节 0=Latin1/1=UTF-16 BOM/2=UTF-16BE/3=UTF-8）+ lofty Vorbis `LYRICS`（FLAC/OGG）。
  - 调研结论：lofty `ItemKey` 无 Lyrics 变体、通用 Tag 转换会丢弃 ID3v2 USLT，故 MP3 必须自研解析；Vorbis 未知键经 `ItemKey::Unknown(String)` 可取到。
  - `is_timed_lrc()` 判别是否带时间轴。
- 导入同步：`import.rs` 的 `import_audio_file()` 在移动源音频**之前**捕获 sidecar，移动/复制后把 `.lrc` 落到目标目录同名 `.lrc`（Move 用 rename、失败回退 copy）；跳过分支也补齐缺失 lrc；`import_ncm()` 暂存 `.ncm` 到 `download/` 时一并搬运 lrc。两条导入路径（自定义文件夹 / 网易云本地曲库）均汇聚 `import_audio_file`，一处改动覆盖全部。
- 后端：`GET /api/lyrics/:id` → `{ok, source("lrc"|"embedded"), timed, text}`。
- 前端：播放器加「词」按钮 + `#lyrics-drawer` 浮层；`parseLrc()` 支持 `[mm:ss]`/`[mm:ss.xx]`/`[mm:ss.xxx]`、一行多时间戳（`.5`→500ms）、`[ti:]`/`[ar:]` 元信息行不入歌词轴、按时间排序；`renderLyrics()` 纯文本整段/时间轴行渲染 + 点击跳转；`syncLyrics()` 高亮当前行 + 居中滚动（幂等）；`timeupdate` 驱动。
- 验证：真实 MP3 + GBK 编码 lrc → 导入 → 曲库内 `.lrc` 落位 → `/api/lyrics/1` 返回 `source=lrc, timed=true` → 前端 Node 断言 parseLrc 17/17、syncLyrics 9/9。
- 注意：Windows 文件系统大小写不敏感，sidecar 单测断言须小写比较（"song.lrc" 与 "Song.lrc" 同文件）。

- **用户提问「导入的曲库里有 ncm 但没配置 ncm 工具会怎么处理」→ 已完整实测并写入 README 新章节**：
  - **导入时**：普通音频正常入库；`.ncm` **不入库**（DB 无任何记录），复制/移动到 `<曲库>/download/pendingNcm/` 暂存，`ImportResult.pending` +1；源文件 copy 模式保留、move 模式移入 pendingNcm（不删）。
  - **界面**：`/api/status` 的 `pending_ncm` 给出积压数；设置面板 NCM 区显示「未配置（无 NCM 工具时，.ncm 文件会进入 download/pendingNcm 暂存）」；导入结果显示「待转换 N」。
  - **指定工具后自动回补**：`POST /api/ncm-tool` 保存工具路径后立即触发 `process_pending_ncm`，返回 `backlog{imported,skipped,pending,failed}`。实测 ncm→wav 成功入库 1、pending 归 0。

  - **唯一开关 = `tool_ready()`**（工具路径指向真实存在的文件），无 enabled/auto_convert 额外开关。

- **关键实现位置**：`app/core/src/import.rs` `import_ncm()`（三分支）/ `process_pending_ncm()`；`app/core/src/config.rs` `NcmConfig::tool_ready()`；`app/core/src/serve.rs` `ncm_tool_handler`（指定工具后回补）/ `ncm_organize_handler`。
