# K music

**K music** 是一个 Windows 桌面端的**本地音乐曲库管理 + 播放器**。它帮你把散落在硬盘各处的音乐整理成结构化的本地曲库，并提供流畅的桌面播放体验。

> 纯本地、不联网、不登录：所有扫描、导入、播放都在你本机完成。所有联网需求需要用户发起。

## 主要功能

- **曲库扫描建索引**：自动识别采样率 / 位深 / 码率 / 声道等，增量扫描不重复处理。
- **外部曲库导入**：复制或剪切导入，自动按 `<艺人>/<专辑>/<曲名>` 归位，并可同步导入同名 `.lrc` 歌词。
- **桌面播放**：底部播放栏（播放 / 暂停 / 拖动进度）；支持上一首 / 下一首、随机、列表循环。
- **播放列表**：自建列表（新建 / 重命名 / 重排 / 加入歌曲 / 移除 / 删除）；支持 JSON 无损备份与 M3U8 导出导入。
- **歌词显示**：同名 `.lrc` 边车 + 音频内嵌歌词；按时间轴高亮、自动滚动、点击跳转。
- **分组浏览**：全部曲库 / 播放列表 / 专辑 / 歌手四类入口。
- **外观自定义**：浅色 / 跟随系统 / 暗色主题 + 主题色 + 换肤（玻璃拟态）。
- **应用设置**：曲库目录、导入策略、列表显示项与列宽、播放偏好等（分 app 级与曲库级配置）。
- **右键菜单**：播放 / 下一首播放 / 加入播放列表 / 打开文件所在位置 / 复制信息 / 删除歌曲到回收站。
- **体验细节**：单实例（同一时刻只运行一个窗口）、窗口位置记忆、启动外观无闪烁。

## 下载与运行（普通用户）

1. 到 Releases 下载最新版，解压后双击 `k_music.exe` 即可使用。
2. 运行需要本机已安装 **Microsoft Edge WebView2 运行时**：
   - Windows 11 通常已自带；
   - Windows 10 若双击后打不开 / 白屏，请安装 WebView2 Evergreen 引导器：
     <https://go.microsoft.com/fwlink/p/?LinkId=2124703>
   - （安装一次后永久可用，无需随包分发。）

首次使用在设置里指定你的音乐曲库目录，应用会自动扫描建库。

## 从源码编译（贡献者）

### 构建前提

- 安装 Rust 工具链（stable）：<https://rustup.rs>
- Windows：安装 **Visual Studio Build Tools（含 MSVC C++）**（`rusqlite` bundled 需 C 编译器与链接器）

### 构建与运行

```bash
cargo build --release -p mt-gui     # 构建 GUI（产物 target/release/mt-gui.exe）
cargo build --release -p mt-cli     # 或仅构建 CLI
cargo test -p mt-core -p mt-gui     # 运行单元测试

cargo run -p mt-gui                 # 运行 GUI（自动启动本地 HTTP 服务并打开窗口）
cargo run -p mt-cli -- scan                   # CLI：扫描曲库建索引
cargo run -p mt-cli -- import "D:/some/folder" # 从外部文件夹导入
cargo run -p mt-cli -- import-netease          # 从本地网易云曲库目录增量合并
```

构建完成后，可用 `tools/package_gui.bat` 一键打包出 `dist/`（含 `k_music.exe` 与 `mt-cli.exe`）。

## 关于 NCM（合规说明）
本应用的正常使用不依赖NCM相关工具。
本项目**不内置、不实现**任何音频解密；仅提供可配置接口，调用**你自备**的 NCM 转换工具。
项目**不随包分发**也不公开分享任何 NCM 工具或解密后的音频，仅供个人非商业自用。
