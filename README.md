# K music

**K music** 是 Windows 桌面端的**本地音乐曲库管理 + 播放器**：把散落在硬盘各处的音乐整理成结构化的本地曲库，提供流畅的桌面播放体验。纯本地、不登录、不乱删文件；所有扫描、导入、播放都在本机完成。未启用联网功能时不联网；用户启用「新版本检测」后，程序按设置频率检查新版本（仅此一项联网）。

## 主要功能

- **曲库扫描建索引**：自动识别采样率 / 位深 / 码率 / 声道等，增量扫描不重复处理。
- **外部曲库导入**：复制或剪切导入，自动按 `<艺人>/` / `<专辑>/` / `<曲名>` 归位，并可同步导入同名 `.lrc` 歌词。
- **桌面播放**：底部播放栏（播放 / 暂停 / 拖动进度）；支持上一首 / 下一首、随机、列表循环。
- **播放列表**：自建列表（新建 / 重命名 / 重排 / 加入歌曲 / 移除 / 删除）；支持 JSON 无损备份与 M3U8 导出导入。
- **歌词显示**：同名 `.lrc` 边车 + 音频内嵌歌词；按时间轴高亮、自动滚动、点击跳转。
- **分组浏览**：全部曲库 / 播放列表 / 专辑 / 歌手 / 喜爱 / 曲源六个一级入口。「喜爱」是按收藏实时推导的动态集合（不写播放列表）；「曲源」页按来源分组浏览歌曲，「曲源总览」在设置里用于管理来源。
- **外观自定义**：浅色 / 跟随系统 / 暗色三态主题；固定品牌强调色；换肤（所选图片作为界面底层的模糊背景，模糊程度可调）；歌词面板半透明且不透明度可调。
- **联网（默认关闭）**：设置新增独立「联网」页；开启总闸并单独允许「新版本检测」后，程序按设置频率（每天 / 每周 / 每月）在启动时向 `api.github.com` 发起一次只读 GET 获取 GitHub Release 版本元数据（响应上限 256 KiB、8 秒超时、失败静默）。未启用不联网；启用后只做这一项检查。发现更高版本时主界面显示非阻塞提示条并提供下载链接，由用户自行下载：程序不下载、不安装、不写盘，不上传任何曲库 / 机器 / 个人信息，无任何遥测。
- **应用设置**：曲库目录、导入策略、列表显示项与列宽、播放偏好等（分 app 级与曲库级配置）。
- **右键菜单**：播放 / 下一首播放 / 加入播放列表 / 打开文件所在位置 / 复制信息 / 删除歌曲到回收站。
- **体验细节**：单实例（同一时刻只运行一个窗口）、窗口位置记忆、启动外观无闪烁。

## 合规声明

- 请自行保证对自己歌曲文件的合法授权；
- 不内置任何盗版资源；
- 不存储第三方平台音频；
- 仅做本地播放与接口调用示例；
- 商用需自行替换音源授权。

本应用不内置、不实现任何音频解密；自 v0.16.0 起，NCM 转换以「插件」形式提供：你自备的 `ncmdump.exe` 放在应用目录下 `plugin/`，或在「设置 → 插件」页安装，程序仅调用它做转换。项目不随包分发也不公开分享任何 NCM 工具或解密后的音频，仅供个人非商业自用；`plugin/` 目录默认只有说明文件，不含任何二进制。

歌词下载等联网能力不作为本程序插件提供，请使用独立 app 或第三方服务，以分割法律风险。

**版权提示**：转换加密音乐文件的行为本身可能涉及版权问题。请确保你转换的音乐是已购买或拥有合法使用权限的，仅供自己方便使用，不要用于传播。

## 下载与运行（普通用户）

- **安装版（推荐）**：到 Releases 下载 `k-music-setup-0.16.2-x64.exe`，双击按向导安装，自动创建开始菜单 / 桌面快捷方式，并自带卸载程序；首次安装若系统缺少 WebView2 会静默补装。
- **便携版**：下载 `k-music-v0.16.2-windows-x64.zip`，解压后双击 `k_music.exe` 即可使用（无需安装）。
- 运行需要本机已安装 **Microsoft Edge WebView2 运行时**：
  - Windows 11 通常已自带；
  - Windows 10 若双击后打不开 / 白屏，请安装 WebView2 Evergreen 引导器：
    <https://go.microsoft.com/fwlink/p/?LinkId=2124703 />
  - （安装一次后永久可用，无需随包分发。）

首次使用在设置里指定你的音乐曲库目录，应用会自动扫描建库。
