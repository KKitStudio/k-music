    设置本地曲库目录

    扫描、导入和下载的音乐将使用此目录。目录不存在时会自动创建。

    欢迎使用 K music — 初始化曲库

    首次使用需指定曲库目录，并选择文件组织方式与 NCM 工具。

    第 1 步：指定曲库目录

    音乐文件与曲库数据（.mt）都将存放在此目录下。

    第 2 步：选择曲库文件结构方案

    决定音乐文件在曲库中的组织方式（之后可在设置中切换并重排）。

    第 3 步：NCM 解密工具（可选）

    若你有 .ncm 格式音乐，可在此指定 ncmdump.exe；没有可稍后在设置里配置。

    请注意，转换加密音乐文件的行为本身可能涉及版权问题。请确保你转换的音乐是已购买或拥有合法使用权限的，仅供自己方便使用，不要用于传播。

    未指定 NCM 工具

    第 4 步：本地网易云音乐曲库目录（可选）

    若你已在网易云 App 内维护了一份本地曲库，可在此指定其目录； 之后点「从本地网易云曲库更新」即可把新歌增量合并进来（只加不删，绝不删除原曲库文件）。没有可跳过。

    管理曲库、外观与导入选项

    界面外观

    主题模式、皮肤背景与歌词面板

    外观（主题 / 换肤 / 歌词）

    主题模式
    布局

    调整曲库 / 列表行高与内边距，实时生效并自动保存，下次启动沿用。
    皮肤背景（在界面底部绘制并模糊所选图片，自动提取主题色）

    曲库

    曲库位置、名称与文件组织方式

    曲库位置

    曲库名称

    用于标识本曲库，便于在多曲库 / 多用户场景下区分。修改后写入本曲库的 .mt/config.toml。

    曲库文件结构方案

    切换方案会按新结构整体移动 / 重命名文件，目录结构将大幅变化；建议先确认媒体播放器已退出本曲库。

    导入

    解密工具与本地网易云曲库增量合并

    NCM 解密工具

    请注意，转换加密音乐文件的行为本身可能涉及版权问题。请确保你转换的音乐是已购买或拥有合法使用权限的，仅供自己方便使用，不要用于传播。

    本地网易云音乐曲库

    指定你在网易云 App 内维护的本地曲库目录（导入源）；点「从本地网易云曲库更新」即可增量合并新歌（只加不删）。

    同步 / 导入历史

    曲库的同步与导入流水单独记录在 .mt/sync-import.jsonl 中；重复对比窗口会把上次选择作为默认预选项。清除后可重新对比同一首歌。

    列表

    歌曲列表显示哪些列、按什么顺序，以及各页面的布局风格

    布局风格

    横向：曲目详情显示在窗口右侧的独立详情栏；
    纵向：曲目详情内联到歌曲列表上方，把宽度让给列表（长曲名 / 艺人 / 专辑不易被截断）。

    歌曲列表显示项

    勾选要在列表中显示的列；用 ↑ / ↓ 调整显示顺序。「导入时间」默认显示，「创建时间」默认不显示，勾选后点「应用显示设置」才会出现在列表里。
    也可以直接在歌曲列表表头上右键，快速打开本页并定位到这里。

      歌曲列表列宽比例

      拖动歌曲列表表头的列分隔线即可调整列宽（解决曲名 / 艺人 / 专辑文字显示不全）。 调整后的比例会保存到配置文件，下次启动自动恢复。

        播放

        自动（无名）播放列表的生成规则

        自动播放列表歌曲数上限

        在曲库 / 专辑 / 歌手页面播放歌曲时，会按当前列表顺序自动生成一个临时播放队列， 最多列入 n 首（默认 20，范围 1–200）。
        该数值只影响自动生成的播放队列：不会改动任何播放列表的内容、列表行数或导出文件； 用户自己创建的有名播放列表始终按其全量曲目播放。
        修改后，下一次触发播放时才生效，当前正在播放的队列不变。
        双击左侧二级列表（专辑 / 歌手 / 播放列表）会播放该列表全量曲目，不受此上限约束（FR-24 新增入口）。

        联网

        默认关闭；开启后仅进行只读版本查询

        联网总闸

        本应用默认不联网。开启总闸后，还需在下方单独打开「是否允许新版本检测」才会发起请求。 当前唯一联网点是启动时向 api.github.com 发起一次 只读 GET， 获取 GitHub 正式 Release 的版本元数据（单次响应上限 256 KiB、8 秒超时、无重试、无后台轮询）。 不上传任何曲库、机器或个人信息；程序不会自动下载或安装任何文件，只提供下载链接由你自行决定。

        版本更新检测

        频率按「启动后触发 + 间隔节流」计算，不会在后台定时轮询。关闭总闸时本区灰显、值仍保留。
