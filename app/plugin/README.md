# 插件目录（plugin）

本目录用于存放 K music 的**外部插件工具**。程序启动时会自动探测 `<exe目录>/plugin/`（发布后即 `dist/plugin/`）下的插件文件：

- `ncmdump.exe` / `ncmdump` / `ncmpy.exe` —— NCM 转换器插件（把网易云 `.ncm` 加密文件还原为原始音频）

## 使用方式

1. 在「设置 → 插件」页点击「安装插件…」选择工具文件，程序会自动复制一份到本目录并启用；也可自行把工具文件放进本目录后点「重新检测」。
2. 插件页提供「开启 / 关闭」（临时禁用，文件保留）与「删除」（二次确认后物理删除工具文件）。
3. 「打开插件目录」按钮可直接定位到本目录。

## 合规声明

- 本目录**默认只含本说明文件，不随程序分发任何解密 / 转换二进制**。插件工具由用户自行获取并放置。
- 转换加密音乐文件的行为本身可能涉及版权问题。请确保你转换的音乐是已购买或拥有合法使用权限的，仅供自己方便使用，不要用于传播。
- 歌词下载等联网能力不作为本程序插件提供；如需请使用独立 app 或第三方服务，以分割法律风险。

## 开发者说明

- 当前为 L1 伪插件：只有探测约定与 app 级插件页，没有 manifest、进程协议或动态加载机制。
- 新增插件种类需同时扩展 `mt_core::config::detect_ncm_tool()` 的候选名与插件页列表（当前硬编码仅 NCM 一项）。
