# 音乐管理系统 — 项目方案总览

> 阶段定位：本地曲库管理 + 桌面播放（应用名 **K music**）。本文为总览，详细见各分文档。
> 状态：**核心能力已实现并构建通过**（2026-11-03）。网易云服务端登录/下载已于 2026-10-29 彻底移除，改本地「从本地网易云音乐曲库更新」增量合并；播放列表（本地自建）已实现。

## 1. 背景与目标

用户为网易云音乐 **VIP 会员**，每月享有**数百首**下载额度。希望将「我的歌单」与「我喜欢的音乐」完整备份到本地，并具备：

- **增量备份**：动态变化的歌单/喜欢列表，只下载未备份过的曲目，避免浪费月度配额。
- **本地曲库管理**：扫描建库、抽取音质信息（采样率/位深/码率）、音质足够则不重复下载、更高音质可按策略升级。
- **外部导入**：把自有存量曲库（指定文件夹）以复制/剪切方式纳入管理。
- **桌面播放**：主界面列出曲库、底部播放栏、双击播放/暂停、拖动进度条 seek。
- **NCM 处理**：部分下载为 NCM 加密格式，借助用户自有第三方工具解密（仅去壳、不转码）；因版权原因系统**不内置**解密，仅提供可插拔接口。
- **跨平台弹性**：当前 Windows PC，未来可能迁移至飞牛(NAS)/安卓。

## 3. 技术决策（已冻结）

- **核心语言**：**Rust**（`rustc`/`cargo` stable）。核心逻辑层为**纯 Rust 库 crate**，与平台/UI 无关。
- **UI 壳（必选，非可选）**：**Tauri + Material Web 前端**，PC 阶段默认实现。单文件原生小包（5–15 MB），复用系统 WebView（不打包 Chromium），满足"小又快"与 Material Design（Q6）。
- **交互层构成**：GUI 壳（主界面 + 底部播放栏）为**主交互**；同时提供 **CLI**（`scan` / `import` / `serve` / `import-netease` / `ncm-organize` 子命令）用于 headless 运维。核心层对二者一视同仁。
- **播放方案**：Tauri Web 前端用 HTML5 `<audio>`；Rust 起 localhost 微型 HTTP 服务（支持 Range/206）按 `local_id` 流式提供音频——既实现拖动 seek，又作为"核心提供文件 URL"接口（本地文件 song_id 可空，统一按 local_id 检索，见 docs/03 §2.4）。
- **本地库**：SQLite 单文件（零运维、易迁移）。
- **配置格式**：**TOML**，**双文件**（2026-11-04 拆分）：app 级 `<exe 目录>/kqk-app.toml`（应用设置 + 当前曲库路径）+ 曲库级 `<曲库根>/.mt/config.toml`（曲库名称 / 结构方案 / 目录布局）。Rust `serde` 原生友好。
- **NCM 转换**：外部工具「命令模板」机制，路径可配置，系统只调用、不实现。
- **网易云接口**：本期已**移除**服务端登录/下载（规避非官方接口账号封禁风险，见 §6）。当前版本**不含任何网易云服务端调用**，主同步路径为本地「从本地网易云音乐曲库更新」（copy 官方 APP 维护目录，不联网、不登录）。未来若恢复下载能力，将基于网易云**官方开发者 API**（OAuth 授权），与原非官方 WEAPI 实现无关；下载管理窗口代码保留、UI 暂隐藏以便复用。
- **UI 壳可替换**：核心保持 UI 无关；若未来安卓需原生 Material，可换 Flutter 壳贴同一核心（见 04 §1.2.1–§1.2.2）。
- **排除项**：**Electron 一律排除**（120–250 MB，违背"小又快"）。

## 4. 阶段划分

- **Phase 1（本期）**：上述全部能力在 **PC 桌面端（Tauri GUI）** 落地，含核心库 + CLI + GUI 播放器。
- **Phase 2（增强 / 跨平台）**：飞牛(NAS)/安卓适配（核心不变、换/加 UI 壳）、ID3 标签写入与精细命名、按专辑虚拟视图、可选原生播放增强（EQ/可视化）。

## 5. 决策记录（Q1–Q6 + 追加）

- **Q1 技术栈**：✅ **Rust 核心 + Tauri UI 壳**（用户确认 Rust 路线，认同"小又快"）。
- **Q2 登录**：✅ **扫码登录** + **退出登录**（同步后自动释放设备槽位，防踢其他设备）。
- **Q3 目录**：✅ 顶层 `app/tools/release` 为项目源码与构建；曲库为用户指定的任意目录，应用数据收敛于其下隐藏目录 `<曲库根>/.mt/`（配置/DB/凭证/日志/工具），由 app 级配置 `kqk-app.toml` 的 `last_library_dir` 定位（见 docs/05）。文件组织由 `config.library.file_scheme` 决定（默认 `artist_album`：`<artist>/<album>/<title>`；另 `album`/`artist`/`flat`）；NCM 原文件统一在 `download/ncm` 与 `download/pendingNcm`，旧顶层 `_ncm_raw/` 已废弃。
- **Q4 NCM**：✅ **不删原文件 + 单独存放**；输出格式=原始音频格式（仅去壳不转码）；探测登记。
- **Q5 配额**：✅ **优先服务端动态获取**；回退=软上限 + 服务端本月记录为已下载真值 + 服务端拒绝为最终权威。
- **Q6 UI**：✅ **Material Design**。
- **存储/匹配/升级（追加）**：✅ 布局已定；匹配=`clean_name_db`（下载写 `song_id→path` 入 DB，存量模糊匹配低置信标待确认）；升级=`ask` 批量确认、`desired_tier=lossless`、`replace_lower=false`。
- **导入（追加）**：✅ 指定文件夹 + copy(默认)/move(破坏性须确认+先写后删)。
- **播放（追加）**：✅ Tauri Web + `<audio>` + Rust localhost Range 服务。

## 6. 法律 / 合规姿态（持续关注，实现中主动提示）

- 设计采用「**不内置 NCM 解密、仅调用外部工具**」降低风险，但**非零法律风险**（规避技术措施抗辩力度因法域而异）。
- 已采纳的缓释承诺（用户明确）：① 绝不重新分发解密（转码后）音频；② 绝不公开分享 NCM 工具、对外发布 app 也**不内置**该工具（打包须显式排除 `tools/ncm/bin`）；③ 持续关注法规。在此承诺下实际法律风险已很低。
- 复用网易云非官方接口另涉**服务条款/账号封禁**风险（非版权）。**本期决策（2026-10-29，当日二次更新）**：**已彻底移除网易云服务端登录与下载功能**（非"默认关闭"），彻底规避封号风险。改由用户在官方 APP 内自行维护（下载）曲库、再以本地「从本地网易云音乐曲库更新」增量合并，全程不联网、不登录。原扫码登录 + 登出 + 释放设备槽位等 WEAPI 相关逻辑一并删除；未来若恢复下载，将基于官方开发者 API 另起授权模块，与原实现无关。
- ⚠️ 工程视角提示，**非法律意见**；正式合规判断请咨询律师。
