# 01 需求分析 — 网易云音乐备份 + 本地曲库 + 桌面播放

> 定义 Phase 1 的功能需求(FR)、非功能需求(NFR)、约束与用例，作为设计与实现基准。技术栈已冻结为 **Rust 核心 + Tauri GUI 壳**（见 00 / 04）。

## 1. 业务背景

- 用户为网易云音乐 **VIP 会员**，每月**有限下载额度**（约数百首）。
- 备份目标：全部**歌单**（自建/收藏） + **我喜欢的音乐**，且集合**持续变化**，需定期增量同步。
- 部分曲目官方下载为 **NCM 加密格式**，需用户自有第三方工具解密（仅去壳，不转码）。
- 本地可能已有曲库文件，需先建库扫描、抽取音质；已存在且音质足够的不重复下载，更高音质可按策略升级。
- 需支持把外部存量曲库**导入**管理（复制/剪切）。
- 需要一 **桌面播放器**：列出曲库、底部播放栏、双击播放/暂停、拖动进度条。

- **策略调整（2026-10-29，二次更新）**：鉴于服务端批量下载存在账号封禁风险（非版权，见 00 §6），**已彻底移除网易云服务端登录与下载功能**（非"默认关闭"），相关 WEAPI/扫码逻辑一并删除。改由用户在网易云官方 APP 内自行维护（下载）曲库，再通过本工具的本地「从本地网易云音乐曲库更新」增量合并进曲库——全程不联网、不登录。NCM 解密能力不受影响，始终可用。

## 2. 角色与使用场景

- **普通用户（本人，PC）**：打开 GUI → 浏览/播放本地曲库 → 点「从本地网易云音乐曲库更新」选择官方 APP 维护的目录做增量合并（不删原曲库、自动处理 .ncm）；或导入任意外部文件夹。应用本质 = 本地曲库管理 + 桌面播放器；**不含任何网易云服务端登录/下载**（已于 2026-10-29 移除），本地导入为唯一同步路径。
- **网易云服务端能力已移除**：原「配置网易云音乐 / 下载 / 更新云音乐曲库 / 下载管理」等入口已从 UI 删除；仅保留本地「从本地网易云音乐曲库更新」与始终可用的 NCM 设置（见 FR-12/FR-14）。
- **运维者（headless）**：CLI 执行 scan / import / import-netease（本地导入），用于定时任务或 NAS。

### 典型场景

1. **首次全量备份**：拉取所有歌单/喜欢 → 本地无曲 → 全量下载（受配额约束，可能跨月分次）。
2. **日常增量备份**：新增喜欢的曲目 → 仅下载新增 → 配额内完成。
3. **本地已有曲库**：扫描 musiclibrary → 抽取采样率/位深/码率 → 建索引 → 已存在且音质足够则跳过。
4. **音质升级**：本地 320k MP3、服务端有 FLAC/Hi-Res → 列出可升级清单一次性确认 → 批量升级。
5. **失败续跑**：部分因 VIP/区域限制失败 → 记录 → 可重试/跳过。
6. **NCM 转换**：下载得 `.ncm` → 配置工具则解密还原 → 单独存放并登记；未转换前列表中标"待转换"。
7. **导入**：指定外部文件夹 → 复制或剪切进曲库并按 `file_scheme` 组织归位（默认 `<artist>/<album>/<title>`）→ 登记入库。
8. **播放**：主界面列曲库 → 双击歌曲 → 底部播放栏播放/暂停 → 拖动进度条跳转。
9. ~~登录槽位管理~~（**已移除，2026-10-29**）：原扫码登录 + 同步后自动登出释放设备槽位逻辑随服务端功能一并删除；本工具不再持有任何网易云登录态。
10. **从本地网易云音乐曲库更新（本地，规避封号）**：用户在官方 APP 内维护（下载）目录 → 点「从本地网易云音乐曲库更新」选该目录（首选项/设置页可记忆）→ 本地增量合并（copy、不删原曲库、遇 .ncm 自动转换）→ 浏览/播放。全程不联网、不登录。

## 3. 功能需求

### FR-01 账号登录、登录态与退出登录 ⛔ 已移除（2026-10-29）
- 原扫码登录（Q2）+ 登录态持久化（`<曲库根>/.mt/auth.json`）+ 退出登录释放设备槽位的整套逻辑**已随服务端功能移除**，本工具不再持有任何网易云登录态。
- 未来若恢复下载能力，将基于网易云**官方开发者 API**（OAuth 授权）另起授权模块，与原有非官方 WEAPI 实现无关（见 00 §3 / 02 §2.1）。

### FR-02 歌单与喜欢列表拉取 ⛔ 已移除（2026-10-29）
- 拉取全部歌单与「我喜欢的音乐」依赖服务端登录，已随 FR-01 一并移除。

### FR-03 本地曲库索引（含音频属性）
- 建立 SQLite 索引，以网易云 **song_id** 为主键（稳定唯一；导入/存量无 song_id 者走模糊匹配）。
- 字段含：名称、艺人、专辑、时长、本地路径、格式、**采样率、位深、码率、声道**、质量层级、状态、needs_review 标记。
- 支持**磁盘扫描回填**与对账（新增/缺失/变更）。

### FR-04 增量差异化下载与音质升级（核心） ⛔ 已移除 / 预留（2026-10-29）
> 以下能力原依赖网易云登录与服务端接口，2026-10-29 随登录功能移除；**UI 隐藏、代码保留**以便未来基于官方开发者 API 复用下载窗口。当前版本无服务端下载路径。原 `[quota]/[quality]/[download]` 配置段已一并删除（非预留）。
- 每次同步：拉取远端 → 与本地索引比对 → 生成**待处理清单**。
- **跳过**：本地已存在且音质 ≥ `desired_tier`。
- **下载**：本地不存在。
- **升级（按策略）**：本地存在但音质 < 可获取最高层级 且 符合 `upgrade_policy` → 下载更高音质（替换或并存按 `replace_lower`）。
- `upgrade_policy=ask` 时：**先扫描出可升级清单，一次性列表展示，用户确认一次即批量处理**（非逐文件弹窗）。

### FR-05 月度配额管理（动态获取 + 回退） ⛔ 已移除 / 预留
- **优先服务端动态获取**上限与剩余（NeteaseCloudMusicApi「会员本月下载歌曲记录」可权威统计已下载；官方 App 展示剩余说明服务端掌握上限/剩余）。
- 若服务端未直接暴露上限/剩余，回退：**可配置软上限** + 以服务端本月记录为**已下载真值** + 服务端拒绝(QUOTA)为**最终权威**。
- 达上限或剩余 0 → 停止下载并提示，已下载保留。

### FR-06 下载执行与容错 ⛔ 已移除 / 预留
- 并发下载（可配置，默认保守）。
- 失败分类：VIP 专享 / 区域·版权限制 / URL 失效 / 网络错误 / 配额耗尽。
- 失败不中断整体；记录原因，支持重试/跳过。
- 文件按网易云返回格式/音质保存（可能 ncm/flac/mp3 等）。

### FR-07 NCM 外部转换接口（可插拔）
- 用户指定第三方工具路径（不内置、不涉及版权），路径可配置。
- 检测工具是否存在；不存在则跳过并提示。
- **工具就绪即自动转换**：指定了工具（`tool_ready()=true`）后，下载/导入/散落发现的 .ncm 一律自动转换；无工具时暂存 `download/pendingNcm/`（不丢文件，配置工具后自动清积压）。
- **不删除原 NCM，原文件单独存放**：有转换工具时，原始 `.ncm` 归档于 `download/ncm/`；无工具时暂存 `download/pendingNcm/`（旧顶层 `_ncm_raw/` 已废弃，统一到 `download/` 体系，见 docs/05 §11）。
- 解密后**格式=原始音频格式**（仅去壳）；系统**探测产物格式并抽取音质属性**后登记。
- 失败处理：超时/非零退出/无产物 → 标记 failed，不删原文件，不阻断主流程。

### FR-08 统计与日志
- 输出：扫描新增/命中、新增下载、升级下载、跳过、失败、NCM 转换、剩余配额。
- 持久化日志，便于排查与配额核对（不在日志明文输出敏感信息）。

### FR-09 本地曲库扫描建库（scan 子命令）
- 独立 `scan` 命令：扫描 musiclibrary，抽取音频属性，建立/更新索引；不触发下载。
- **匹配策略 `clean_name_db`**：
  - 主（可靠）：本工具下载/导入时自控制文件名，并立即写 `song_id → file_path` 入 SQLite；文件名不含 song_id，关联靠 DB（真相源）。
  - 辅（存量回溯）：对启用前已有文件，按 标题+艺人+专辑 元数据模糊匹配 song_id；低置信度标 `needs_review`。
- 结果写入 songs / download_records（含音质字段）。

### FR-10 歌曲导入（指定文件夹，复制/剪切可选）
- 指定**外部源文件夹**（不在 musiclibrary 内），将其音频文件**导入并整理进曲库**。
- **方式可选**：
  - `copy`（默认、推荐）：保留源，库内新增，无数据风险。
  - `move`（剪切）：写入校验成功后删源（节省空间）。**破坏性**——执行前显式确认 + 先写后删，任一步失败即中止保留源，绝不半删。
- **落盘整理**：按 `config.library.file_scheme` 组织（默认 `<artist>/<album>/<title>.<ext>`，见 docs/03 §6）；艺人/曲名取自音频标签，缺失回退文件名解析并标待整理。
- **入库登记**：导入后立即对该批文件抽取属性并 DB 登记（复用 FR-09 逻辑）。
- **song_id 关联**：导入文件通常无 song_id，走"存量回溯"模糊匹配，低置信度标 `needs_review`，不擅自绑定下载/升级状态。
- 与 scan 区别：scan 仅索引库内已有；import 从**库外带入并整理落盘**。

### FR-11 曲库浏览与播放（GUI 主界面）
- **曲库列表**：主界面从 SQLite（songs + download_records 的可播放音频）读取并展示 曲名/艺人/专辑/音质/时长。
- **选中详情面板（选中即同步）**：**单击选中**曲库歌曲 → 主界面详情区同步显示该曲信息：**专辑图片、艺人、专辑、格式、采样率、位深、码率、声道、时长、质量层级**。信息来自核心查询（songs + download_records）；与播放解耦（选中≠播放）。
- **专辑图片来源**：从音频文件**内嵌封面**提取（`lofty` 读取 APIC/picture）；无内嵌时当前**不回退外链**，封面接口返回 `204`（网易云专辑图外链回退为待实现项，见 docs/05 §12 待接入清单），列表以占位图呈现。
- **底部播放栏**：当前曲目、播放/暂停、可拖动进度条、时间显示。
- **交互**：双击曲库歌曲 → 载入并播放；单击 → 仅选中并更新详情面板；点击暂停按钮 → 暂停/继续；拖动进度条 → 跳转播放位置。
- **播放实现**：Web 壳用 HTML5 `<audio>`；Rust 起 localhost 微型 HTTP 服务（支持 Range/206）按 `local_id` 流式提供音频（本地文件 song_id 可空，统一按 local_id 检索，见 docs/03 §2.4），既实现拖动 seek，又作为核心"文件 URL"接口。
- **核心解耦**：核心仅提供"列出曲库 + 取文件地址/URL + 取详情(含封面)"的查询接口，不耦合播放逻辑——保证 UI 壳可替换。
- **播放范围**：仅库中**可播放音频**（解密后的常规格式）；`.ncm` 未转换前不可直接播放（列表可展示但标"待转换"，点击触发转换或禁用播放）。

### FR-12 网易云服务端功能已移除（主界面无登录/下载入口）
- 应用本质是**本地曲库管理 + 桌面播放器**；网易云的**服务端登录与下载功能已于 2026-10-29 彻底移除**（非"默认关闭"），主界面不再有任何服务端入口（无「配置网易云音乐 / 下载 / 更新云音乐曲库 / 下载管理」）。
- 原主开关 `netease.login_enabled`、`netease.configured`、`login_method`、`auth_store`、`auto_logout_after_sync` 等字段**一并移除**（见 03 §3、02 §2.1）。
- **NCM 设置区块始终显示**（见 FR-07），与任何开关无关。
- **「从本地网易云音乐曲库更新」按钮始终显示**（见 FR-14）：本地导入入口，是唯一的同步路径。

### FR-13 本地曲库目录设置（指定曲库 = 启动首步）
- **指定曲库是应用运行起来后要做的第一件事**（首次启动初始化向导，见 docs/05 §4a）：向导采集「曲库根目录 + 文件结构方案 `file_scheme` + NCM 工具 +（可选）本地网易云音乐曲库目录」四项后，在曲库根下新建隐藏目录 `.mt/`（写 config.toml / library.db / README.txt、建 `download/{ing,ncm,pendingNcm}` 体系、检测 NCM、写 app 级配置 `kqk-app.toml` 的 `last_library_dir`），随后进入主界面。主界面的「设置」按钮可重新配置这些项（含换曲库位置、切换 file_scheme 触发全量重组、配置 NCM、设置/修改本地网易云音乐曲库目录），「导入歌曲文件夹」只在主界面出现（见 docs/05 §4b/§5b）。**所有本地路径输入（曲库目录 / NCM 工具路径 / 本地网易云音乐曲库目录 / 导入源文件夹）均同时提供文本框 + 系统原生「浏览…」按钮，不允许只靠手输**（见 NFR-02）。
- 已指定过的曲库由 app 级配置 `kqk-app.toml`（exe 同目录）的 `last_library_dir` 记住；失效（目录被移除）才重新引导。
- 路径不存在时自动创建；保存成功后持久化到 `<曲库根>/.mt/config.toml`（`.mt` 内 `download_root = 曲库根`、`ncm_raw_dir = download/ncm` 等），并立即扫描新目录刷新曲库列表；之后的扫描、导入、从本地网易云音乐曲库更新均使用该目录（本地网易云音乐曲库目录另存于 `netease.library_dir`）。
- 路径创建或配置保存失败时显示明确错误，不修改当前运行时目录配置。

### FR-14 从本地网易云音乐曲库更新（本地增量导入，FR-10 特化，规避封号）
- **用途**：用户用网易云官方 APP 自行维护（下载）一个曲库目录后，本工具**本地**读取该目录并增量合并进曲库；全程不联网、不登录，规避服务端批量下载的账号封禁风险（非版权，见 00 §6）。
- **入口**：主界面按钮「从本地网易云音乐曲库更新」（始终显示，与任何开关无关）。
- **源目录配置**：`netease.library_dir`（本地网易云音乐曲库目录）在**首次向导**与**设置页**均可设定（见 FR-13 / FR-15）；设定后该按钮优先使用此目录，仍允许临时改选其他目录。
- **操作**：点按钮 → 选择/确认网易云 APP 的下载目录（已配置 `library_dir` 则直接复用，亦可临时改选）→ 扫描其中音频与 `.ncm`。
- **行为**：
  - **copy 模式、不删原曲库文件**：源目录与原曲库均保留；新增文件按 `config.library.file_scheme` 归位入库，已存在且完整者跳过（增量门控，03 §5.1）。**单向合并**：仅把网易云目录中"曲库没有"的曲目加入曲库；不反向删除曲库已有曲目，也不因网易云目录删歌而删曲库（见下方"业务逻辑待确认"）。
  - 遇 `.ncm`：工具就绪（`tool_ready()`）则自动转换入库（原 .ncm 归档 `download/ncm`）；无工具则暂存 `download/pendingNcm`（不丢文件，见 FR-07）。
  - 与 FR-10 区别：FR-10 为任意外部文件夹、可 `move`（破坏性）；FR-14 固定为网易云 APP 目录、强制 `copy`、语义为「同步更新」而非「搬移」。

### FR-15 本地网易云音乐曲库目录设置（源目录配置，与 `library_dir` 区分）
- **两个目录务必区分**（关键，避免混淆）：
  - `library_dir` = **本工具曲库**（扫描/播放根，由 FR-13 指定，应用所有音频归位此处）。
  - `netease.library_dir` = **本地网易云音乐曲库（导入源）**，由用户在网易云官方 APP 内维护（下载）的目录；本工具只从中**读取并 copy 进 `library_dir`**，绝不写回、绝不删除其中文件。
- **配置入口**：① 首次启动向导（FR-13 第四项，**可选**，用户可跳过、日后设置页再配）；② 设置页「本地网易云音乐曲库」区块（含文本框 + 浏览按钮，见 NFR-02）。
- **持久化**：写入 app 级配置 `<exe 目录>/kqk-app.toml` 的 `[netease] library_dir`；为空时「从本地网易云音乐曲库更新」按钮点击后引导用户先选目录（不报错退出）。
- **用途**：供「从本地网易云音乐曲库更新」按钮记忆默认源目录；CLI `mt-cli import-netease` 也可用其作为默认参数（可 `-p <目录>` 覆盖）。

## 4. 非功能需求

- **NFR-01 跨平台**：核心逻辑不依赖 Windows 专有 API；路径/编码可移植（未来 飞牛 Linux / 安卓）。
- **NFR-02 可配置 + 路径输入必带浏览按钮**：`file_scheme`、NCM 工具路径、导入默认方式（copy/move）、扫描/播放服务等可配置化（TOML）；服务端下载相关 `[quota]/[quality]/[download]` 配置段已随功能删除（2026-10-29）。**所有本地路径类输入（曲库目录 / NCM 工具路径 / 本地网易云音乐曲库目录 / 导入源文件夹）必须在 UI 上同时提供文本框与系统原生「浏览…」按钮，不允许仅手输路径**（见 FR-13 / FR-15）。
- **NFR-03 可观测**：清晰进度、结果汇总、错误明细。
- **NFR-04 容错与幂等**：中断可续跑；重复运行不重复文件/计数；扫描可重复执行。
- **NFR-05 小又快**：单文件原生二进制（目标 5–15 MB）、零运行时依赖、启动快；**排除 Electron**。
- **NFR-06 Material Design**：UI 统一 Material 规范（Q6）。

## 5. 约束与限制

- **版权合规**：不破解/不内置 NCM 解密；仅调用用户自有工具（C1）。
- **配额不可绕过**：网易云月度额度为服务端限制，工具只能尊重（C2）。
- **接口稳定性**：网易云接口可能变动，接口层独立、单测覆盖（C3）。
- **本地文件视为缓存备份**：不承诺永久可用（C4）。
- **NCM 不可直接分析/播放**：加密文件需解密后才能抽取音质/播放；原文件本身不解析（C5）。

## 6. 项目目录结构（Q3 已定）

```
musicMT/                                # 项目源码与构建（顶层固定）
├─ app/            # 项目源码(core lib + cli + tauri 壳)
├─ tools/          # 开发工具 与 NCM 转换工具源(如 tools/ncm/，构建发布须排除 bin)
├─ release/        # 构建产物
└─ <曲库根>/       # 用户指定的曲库（例：musiclibrary），数据随曲库走
   ├─ download/                   # 已下载完成文件（download/ing 下载中、download/ncm 归档、download/pendingNcm 暂存）
   ├─ <artist>/<album>/...        # 音乐文件（按 file_scheme 组织，默认 artist_album）
   └─ .mt/                        # 本应用隐藏数据目录（指定曲库时新建：config.toml/library.db/auth.json/app.log/tools）
```
> 顶层 `app/tools/release` 为项目自身；曲库为用户指定目录，应用数据收敛于其下 `.mt/`，由 app 级配置 `kqk-app.toml` 的 `last_library_dir` 定位。详见 docs/05。
