## 目录内容
- `k_music.exe` —— **主入口**：双击即启动（自带后端 HTTP 服务 + 桌面窗口）。
  > 构建产物原名 `mt-gui.exe`，由 `tools\package_gui.bat` 在拷入发布目录时改名；手动从 `target\release\` 拷贝时也请改成此名，避免与旧入口并存。
- `mt-cli.exe` —— 命令行工具（可选）：`scan` / `import` / `import-netease` / `ncm-organize` / `library` / `serve` / `--version`。
- `frontend/` —— 前端静态资源（GUI 后端同源提供，请勿删除或改名）。
- `plugin/` —— 插件目录，默认只有 `README.md` 说明。需要转换网易云 `.ncm` 加密歌曲时，在此目录放入你自备的 `ncmdump.exe`，或在「设置 → 插件」页点「安装插件…」自动复制进来。程序不随包分发任何解密工具。

## 使用
1. 双击 `k_music.exe`。
2. 首次启动进入「初始化向导」：选择曲库目录、**填写曲库名称**、文件结构方案（默认 `artist_album`），随后可选「本地网易云音乐曲库目录」。如需转换 `.ncm` 加密歌曲，初始化完成后到「设置 → 插件」安装 NCM 转换器（向导不再指定工具路径）。
3. 设置完成后即可看到曲库主界面。

> 后端服务端口由系统自动分配（默认配置 `server.port = 0`），无需手动指定；旧实例未退出时已自动回退到空闲端口，不会卡死。

## 运行时生成的文件
- `kqk-app.toml` —— **app 级配置**（本目录内）：应用自身设置（NCM 工具、本地网易云导入源、显示列偏好、服务器等）**外加当前曲库路径** `last_library_dir`。
- `.guest/` —— **由应用自动管理，请勿手动删除**。尚未指定曲库（初始化向导态）或曲库目录失效时，程序在本目录自动创建它，向导期间临时承载界面状态、空的索引库与启动日志；运行期间删除可能导致当前会话异常，且下次回到向导态会自动重建，删了既不省空间也不解决问题。它不是曲库数据；指定曲库后会作为残留留在原处，同样无需清理，你的曲库数据始终在 `<曲库目录>/.mt/`。
- `<曲库目录>/.mt/` —— **曲库级配置与数据**：`config.toml`（曲库名称 / 文件结构方案 / 目录布局）、`library.db`（索引）、`app.log`（GUI 运行诊断日志）、`trash/`（删除歌曲的可取回区）、`pending-duplicates.json` + `pending-duplicates/`（重复文件的未决组与挂起文件）、`sync-import.jsonl`（独立的同步 / 导入操作流水）、`playstate.json`（播放队列）、`convert/`（v0.17.3 NCM 转换临时中转，用完即清、扫描不会收编）。NCM 工具自 v0.16.0 起改存 app 级 `plugin/`，不在此目录。

> **配置分两类**：属于「应用」的放本目录（`kqk-app.toml`），属于「某个曲库」的放该曲库的 `.mt/` 下。
> 当前曲库路径是唯一例外——它必须放在应用目录，因为应用得先知道当前曲库才能找到它的配置。

> **配置不会被覆盖**：上述运行时文件在重新构建 / 替换 exe 时**一律保留**，本目录下的测试配置
> （当前曲库路径、NCM 工具、导入源、界面偏好）不会丢失，无需每次重新指定曲库；`.guest/` 同样由打包脚本保留，请勿手动删除。
>
> **配置带版本号**：`kqk-app.toml` 与 `.mt/config.toml` 内含 `[meta]` 段，记录生成时的版本号与
> 最低兼容版本号。版本兼容时既有配置**原样保留**，只按需更新 `[meta]`；只有结构/字段不兼容时才会
> 重建（先把原文件备份为 `*.conflict-<版本>.bak`），并在「设置 → 配置文件」中说明冲突原因。

## 从本地网易云音乐曲库更新
- 主界面与设置面板都有 **「从本地网易云音乐曲库更新」** 按钮：把本地网易云曲库里本应用还没有的歌曲
  **复制**进当前曲库（只加不删，不联网、不登录、不碰原曲库文件）。
- **尚未设置网易云曲库目录时**，点击该按钮会直接弹出**目录选择框**；选好目录后自动保存并**立即执行更新**，
  无需再去设置面板手动指定。

## 歌词
- 播放时点击播放器上的 **「词」** 按钮打开歌词面板：按播放进度高亮当前行、自动滚动，**点击某行可跳转**到对应时间点。
- 歌词来源优先级：**同名 `.lrc` 文件**（与歌曲同目录同 stem）→ 音频文件**内嵌歌词**。
  - 内嵌支持：FLAC / OGG 的 Vorbis Comment（`LYRICS` / `UNSYNCEDLYRICS`）、MP3 等的 ID3v2 `USLT` 帧。
- 导入歌曲时会**同步导入同目录同名的 `.lrc` 歌词文件**（自定义曲库导入与「从本地网易云音乐曲库更新」均适用）。
- 歌词文本编码自动识别：UTF-8 / UTF-16 / **GBK-GB18030**（中文 lrc 常见）。

## 外观（v0.7.8 调整）
- **歌词面板半透明**：底色带毛玻璃效果，歌词文字始终不透明。在 **「设置 → 外观 → 歌词面板不透明度」** 用滑块调整（40%–100%，默认 82%）。
- **皮肤背景**：选择本地图片或 5 个预设渐变后，图片只画在**界面最底层**并做模糊，避免细节干扰表格与文字；模糊程度在 **「设置 → 外观 → 皮肤背景模糊」** 调整（0–40px，默认 18px，0px 为原图）。
- **不再提供主题色设置**：主题色固定为品牌蓝（浅色 / 暗色各一），换肤也**不会**再从图片提取颜色去改主题色；明暗三态主题（浅色 / 跟随系统 / 暗色）与顶部切换按钮保留。
- 以上两个滑块写入 `<exe目录>/kqk-app.toml` 的 `[ui]` 段，重启后保持；皮肤图片本体只存浏览器本地缓存，不会写进配置文件。
- 主界面顶部已**去掉「下一首播放」按钮**；需要插播请用歌曲右键菜单「下一首播放」或队列面板。

## 联网与版本检测（v0.8.1 新增，默认关闭）

**本应用默认不联网。** 如需检查新版本，请打开 **「设置 → 联网」**，先开启「允许联网功能」总闸，再单独打开「是否允许新版本检测」；总闸关闭时下方子项灰显不可操作（已设置的值会保留）。

- 目前唯一更新源为 **GitHub**，检查频率可选**每天 / 每周 / 每月（30 天）**，默认每天；也可点「立即检查」强制执行一次。
- 允许检测后，程序在**启动时**异步向 `api.github.com` 发起**一次只读 GET**，只取正式 Release 的版本号与页面链接：响应上限 **256 KiB**、**8 秒超时**、无重试、无后台轮询。它**不返回也不下载安装包**；程序只读版本元数据，**不会自动下载 / 安装 / 写盘**，只在新版本出现时提供「前往下载」链接由你自行决定。
- **不上传任何曲库、机器或个人信息**，无任何遥测；网络不可达、GitHub 限流或返回异常一律**静默跳过**，不影响使用，也不弹错误框。
- 检测到更高版本时，主界面顶部显示一条**非阻塞提示**，「稍后」可本次隐藏；「设置」按钮与「关于」标签会出现红点，点一次设置即消失，关于红点会在程序版本落后期间保留，升级后自动熄灭。
- 子项**「是否允许远程下载歌词（暂未开放）」为灰色占位**，功能尚未实现、不产生任何网络行为。
- 检测成功仅在曲库 `.mt/app.log` 写一行版本号记录（如 `local=0.8.1 remote=0.9.0`）；缓存与红点已读状态只存 WebView 本地存储，不写入 `kqk-app.toml`。

## 想自己重新打包？
项目根目录执行 `tools\package_gui.bat`（Windows 双击即可）：编译 release，把 `target\release\mt-gui.exe` 拷成 `k_music.exe`、`mt-cli.exe` 原样拷入，并清理旧版残留的 `dist\mt-gui.exe`（避免两个入口并存）。**前端静态资源（`frontend/`）已由 `app/gui/build.rs` 在 `cargo build` 编译期自动同步到本文件夹**，无需手动拷贝。

> 打包脚本**不会删除或覆盖**本目录下的运行时配置（`kqk-app.toml` / `.guest\` / `library.db` / `app.log`），你在 `dist\` 里的测试配置会一直保留；其中 `.guest\` 由应用自身管理，同样请勿手动删除（详见「运行时生成的文件」）。
> 脚本本身必须保持 **CRLF 行尾 + 纯 ASCII**（文件头部有「编写规范」说明）：否则 cmd.exe 解析会错乱，把行拆成非法命令。

## 导入进度（逐首明细）
- 导入 / 从本地网易云曲库更新时，右下角弹出**进度面板**：进度条（已处理/总数）、当前正在处理的文件与动作、**逐条动作日志**、以及入库/跳过/失败统计与「已转换待入库 / 已入库」两行分类计数。转换成功一首即判重入库一首，歌曲列表随导入过程实时增长。
- 动作分四类：**复制** / **移动** / **转换**（.ncm 解密）/ **跳过**（曲库中已存在）。无 NCM 工具时 .ncm 直接跳过、原件留在源目录（不暂存）。
- 例：`[复制] 夜色.mp3 → 已入库`、`[转换] 加密歌.ncm → 已入库`（原始 .ncm 保留在原曲源）。
- 计数口径：进度条与统计按**源文件**计；动作日志按**真实动作**计（1 个 .ncm 源文件会有「转换」+「入库」两条日志，但只结算 1 首）。

## 重复歌曲：挂起与对比（v0.6.1 新增）

- 重复判定口径 = **歌手 + 歌曲名 + 格式**（格式按小写扩展名，同一首歌的 `.flac` 与 `.mp3` **不算**重复）。
- **手工导入 / 扫描曲库**发现同三元组且库内已有记录时，不直接覆盖：新文件先挂到 `<曲库>/.mt/pending-duplicates/`，顶栏出现「待处理重复 N」角标；**启动时的自动扫描只静默登记，不弹窗**，点角标或点「扫描曲库」才打开对比窗。
- 对比窗一次列出**全部未决组**，每组并排显示两份文件的大小 / 采样率 / 位深 / 格式 / 来源，各带「试听」；可逐组选「保留库内」或「采用新的」，最后「应用所选」批量提交；「稍后处理」/ 关窗保持挂起，下次接着处理。
  - 保留库内：手工导入的源文件**原位不动**，扫描发现的挂起项移入 `.mt/trash/`（可手动取回）。
  - 采用新的：库内记录**原地替换**，`local_id` 不变，播放列表引用与播放队列都不丢；同名 `.lrc` 跟随被采用的那一份。
- 从**本地网易云曲库更新 / NCM 回补**（周期性同步）时，目标已存在且大小相同仍静默跳过，不弹窗打断；大小不同才挂起。同一批里出现两个及以上同三元组的新文件，整组挂起。
- 同一来源、同一大小的文件再次导入仍会挂起、仍会弹窗，但会把**上次的选择作为默认预选项**并显示提示；库内文件或源文件大小变化后该预选自动失效。设置 →「导入」里可「清除同步/导入历史」。
- 所有同步 / 导入事件（含跳过、挂起、决策、失败）写入 `<曲库>/.mt/sync-import.jsonl`，**与 `app.log`（运行诊断日志）分开**；换曲库时未决组留在原曲库的 `.mt/` 下，不会自动清理。

## 播放整组、侧栏与音量（v0.7.1 新增）

- **双击左侧二级列表项**（专辑 / 歌手 / 播放列表）= 立即播放该列表的**整组全量**曲目，从第一首开始；
  双击**单首歌曲**仍按「设置 → 播放 → 自动播放列表数量」生成队列并从点击的那首开始播。
- **一级菜单 / 二级分组栏宽度**：拖动栏右缘的窄把手即可调整，两级各自独立记忆；贴在该栏与相邻栏之间的
  `‹ / ›` 细条（见下节「表头右键与歌曲信息栏收缩」）可把该列**整栏隐藏**，再点同一条细条即可展开。
  收起 / 展开状态与宽度重启后自动恢复。
- **音量**：播放条进度条右侧新增音量滑块与静音按钮，拖动即时改变实际音量，点按钮静音 / 恢复原音量；重启后保留、换曲库不变。
- 上述宽度、收缩状态、音量与静音都保存在 `dist\kqk-app.toml` 的 `[ui]` 段（`sidebar_width` / `group_width` /
  `sidebar_collapsed` / `group_collapsed` / `volume` / `muted`），只就地更新，不会抹掉你写的注释或其它设置。
- 专辑 / 歌手 / 全部曲库统一称为**智能播放列表**，播放队列标题与空态都带「智能播放列表 ·」前缀；
  它们仍是自动生成的浏览视图，不写入播放列表数据库，也不支持移除成员 / 重命名 / 重排。

## 表头右键与歌曲信息栏收缩（v0.7.2 新增，v0.7.3 ~ v0.7.9 调整入口）

- **右键任意歌曲列表的表头**（含列宽拖拽手柄）→ 直接打开「设置 → 列表」并滚动、高亮到「歌曲列表显示项」，
  可立刻勾选要显示的列 / 调整顺序；四张歌曲表（全部曲库 / 播放列表 / 专辑 / 歌手）都支持。
- **每栏一条收缩 / 展开细条**：一级菜单、二级列表、歌曲信息栏各只有唯一一条（共 5 条），
  是贴在**该栏与相邻栏之间的间隙**里、从栏顶贯穿到栏底的细条（默认 12px 宽），箭头 `‹ / ›` 垂直居中。
  鼠标**悬停会即时弹出「收起 / 展开 ××」提示**（不是延迟很长的原生提示），点击反馈只作用于细条本身，
  不会切换页面、不会给整项加选中色、也不会改变已选中的歌曲。折叠前后细条的水平位置不变，
  歌曲列表文字不会被压住。纵向布局（播放列表 / 专辑 / 歌手页）时歌曲详情是水平条，
  对应细条也转为**横贯全宽的水平细条**，夹在「歌曲详情」与「歌曲列表」之间，箭头改 `⌃ / ⌄`。
- **收起后整栏隐藏**：一级栏 / 二级栏 / 歌曲信息栏收起时，栏体宽度、内边距、边框、背景全部归零，
  **只留那条细条作为唯一展开入口**，宽度全部还给歌曲列表；歌曲信息栏的专辑封面与文字一起隐藏，
  纵向布局下的内联详情条同步收起。点细条即可恢复。
- 收缩状态分别保存在 `dist\kqk-app.toml` 的 `[ui]` 段 `sidebar_collapsed` / `group_collapsed` /
  `detail_collapsed`，与侧栏宽度 / 音量一样只就地更新，重启后自动恢复、换曲库不变，
  不会抹掉你写的注释或其它设置。
- 入口演变：v0.7.2 顶部 «/» + 悬浮图标 → v0.7.4 合并为唯一居中按钮 → v0.7.5 内嵌为列表项 →
  v0.7.7 贴边线的小方块 → **v0.7.9 贯穿全高的间隙细条**（当前形态）。旧形态均已移除，不再复活。
